# sw_material_set

Assign a material to the part and prove it took by reading the material back and reporting the density and mass it now has.

| | |
|---|---|
| Tier | `core` |
| Domains | `material`, `feature` |
| Document precondition | `part` |
| Safety | `model_mutation` |
| Read-only | False |
| Destructive | False |
| Confirmation required | False |
| Auto-checkpointed | True |
| Idempotent | True |
| Timeout | 180s |
| Partially satisfies | `FEAT-020` |
