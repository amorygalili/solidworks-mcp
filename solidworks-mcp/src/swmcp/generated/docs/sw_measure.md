# sw_measure

Measure the model, a body, a feature, or a single face: bounding box, volume, surface area, mass, centre of mass, topology counts, and rebuild validity.

| | |
|---|---|
| Tier | `core` |
| Domains | `measure`, `body` |
| Document precondition | `part_or_assembly` |
| Safety | `read` |
| Read-only | True |
| Destructive | False |
| Confirmation required | False |
| Auto-checkpointed | False |
| Idempotent | True |
| Timeout | 300s |
| Satisfies | `FEAT-019` |
