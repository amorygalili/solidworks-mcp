# sw_config_delete

Delete a configuration. Destructive: the configuration's own dimension values and property overrides go with it, so it requires confirmation.

| | |
|---|---|
| Tier | `extended` |
| Domains | `parameter` |
| Document precondition | `part_or_assembly` |
| Safety | `model_mutation` |
| Read-only | False |
| Destructive | True |
| Confirmation required | True |
| Auto-checkpointed | True |
| Idempotent | False |
| Timeout | 180s |
| Satisfies | `PAR-003` |
