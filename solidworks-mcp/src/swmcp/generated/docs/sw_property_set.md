# sw_property_set

Write or delete custom properties at file level or in one configuration, and read every one of them back to confirm the value that was actually stored.

| | |
|---|---|
| Tier | `core` |
| Domains | `parameter` |
| Document precondition | `any` |
| Safety | `model_mutation` |
| Read-only | False |
| Destructive | False |
| Confirmation required | False |
| Auto-checkpointed | True |
| Idempotent | True |
| Timeout | 180s |
| Satisfies | `PAR-006` |
