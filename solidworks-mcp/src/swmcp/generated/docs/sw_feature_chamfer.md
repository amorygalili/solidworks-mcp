# sw_feature_chamfer

Bevel edges or faces with an equal-distance or angle-distance chamfer, using stable entity references.

| | |
|---|---|
| Tier | `core` |
| Domains | `feature` |
| Document precondition | `part` |
| Safety | `model_mutation` |
| Read-only | False |
| Destructive | False |
| Confirmation required | False |
| Auto-checkpointed | True |
| Idempotent | False |
| Timeout | 300s |
| Satisfies | `FEAT-006` |
